# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for your interest in improving this project.

## How to Contribute

1. Fork the repository and create a new branch from `main`.
2. Make your changes and test the script locally with `./simple-interest.sh`.
3. Commit your changes with a clear, descriptive message.
4. Push the branch and open a pull request describing your change.

## Reporting Bugs

Open an issue with:

- What you expected to happen
- What actually happened
- Steps to reproduce the problem
- Your operating system and Bash version

## Suggesting Enhancements

Ideas for new features, performance improvements, and documentation updates are all welcome. Please open an issue describing the enhancement and why it would help users.

Please feel free to open an issue or submit a pull request for any improvements.
